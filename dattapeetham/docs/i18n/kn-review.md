# Kannada (ಕನ್ನಡ) site: notes for the native reviewer

The Kannada site lives at `/kn/`. It was translated in six parallel machine-assisted chunks (the
"translators" in this note; they are not six people), and no fluent speaker has reviewed it yet:
that is your review. It was then put through one
editorial pass that made names, terms and UI labels consistent across all pages. This note
lists what was decided, what only the Ashram can confirm, and where to start reading.

The rules every translator followed are in `src/i18n/glossary/kn.md` (style guide) and
`src/i18n/glossary/kn.json` (about 1,300 fixed spellings). Section 10 of the style guide records
the decisions from the editorial pass.

**Register.** Standard written Kannada. Sri Swamiji, Sri Bala Swamiji, Sri Jayalakshmi Maata,
the Gurus and Lord Dattatreya always take the respectful plural (ಹೇಳುತ್ತಾರೆ, ಅನುಗ್ರಹಿಸಿದರು).
The reader is addressed as ನೀವು with polite imperatives (ಭೇಟಿ ನೀಡಿ, ಸಂಪರ್ಕಿಸಿ). Quotations of
Sri Swamiji keep his own voice (ನಾನು, ನಾವು, ನೀವು).

**UI labels** have one rendering everywhere: ದೇಣಿಗೆ ನೀಡಿ (Donate), ಪೂಜೆ ಕಾಯ್ದಿರಿಸಿ (Book a Puja),
ನಿಮ್ಮ ಭೇಟಿಯನ್ನು ಯೋಜಿಸಿ (Plan your visit), ಇನ್ನಷ್ಟು ಓದಿ (Read more), ದಾರಿ ತಿಳಿಯಿರಿ (Get
directions), ದೇವಸ್ಥಾನಗಳು ಮತ್ತು ದರ್ಶನ (Temples & Darshan), ಅಧಿಕೃತ ದಿನದರ್ಶಿಕೆ (Official
calendar). The glossary suggests ನೇರಪ್ರಸಾರ for the new "Live streams" link.

**Numbers and times.** Western digits exactly as in English (the build checks them). The part of
the day comes before the time: ಬೆಳಿಗ್ಗೆ 6:00 – ಮಧ್ಯಾಹ್ನ 12:00, ಸಂಜೆ 4:00 – ರಾತ್ರಿ 8:00. Running
text uses Kannada date order (2004ರ ಮೇ 29ರಂದು). Cards and chips keep the English order
(29 ಮೇ 2004).

**Book titles.** English-language editions keep their published English title in Latin
(Datta Speaks, Reflections of the Absolute). Indian-language editions, Sanskrit included, get the
Kannada title. The language tag is always in Kannada (ಇಂಗ್ಲಿಷ್, ತೆಲುಗು).

## (d) How to change a translation

1. Find the English sentence in `src/i18n/segments.json` or search the Kannada text in
   `src/i18n/kn/part-*.json`. Each file is `{ "exact English": "ಕನ್ನಡ" }`.
2. Edit only the Kannada value. Never change the English key; a changed key no longer matches
   the page and the sentence falls back to English.
3. Keep every placeholder (`<1>…</1>`, `<2/>`, `%1`) and every number exactly as in the English.
   You may move placeholders to suit Kannada word order.
4. If you change a name or term, change it in `src/i18n/glossary/kn.json` too, and search the
   part files for its other occurrences.
5. Check and rebuild:

   ```
   cd dattapeetham
   node tools/i18n-check.mjs kn     # must report 0 problem(s)
   node build.mjs                   # kn must show 0 rejected
   ```

   Then open `site/kn/<page>.html` (or the dev server, `node build.mjs --serve`, at
   http://localhost:4321/kn/).
