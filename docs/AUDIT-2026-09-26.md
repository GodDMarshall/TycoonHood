# TYCOONHOOD — Takeover audit, 26 September 2026

Performed at the start of the Claude Code takeover, on a fresh Linux checkout (Node 22, pnpm 9.15.9,
PostgreSQL 16), after migrating and seeding, running every gate and opening the product in a real browser at
1440px and 390px. Findings are what was observed, not inferred. The right-hand column says what happened next.

## Baseline (before any change)
Typecheck clean · lint clean · **101/101** unit tests · both builds green · 47 web routes.

## Findings

| Area | Finding | Action |
|---|---|---|
| **Product** | The platform underneath is real and strong: double-entry ledger with provable supply, academy with quizzes and certificates, missions as data, challenges with review, sized merch with atomic stock, the Miner, an admin console. | **Kept all of it.** No business logic was rewritten. |
| **Visual** | Template feel: system fonts (Georgia + Segoe), 14px-radius cards everywhere, a text-only hero, rounded pills, emoji as icons (🔥 🏅 ⛏ 🎓). | Rebuilt the system (DR-17). |
| **Brand** | "Ledger" identity read as a generic dark theme; nothing spatial, nothing ownable except the coin mark. | The HQ: districts, the 3D headquarters, pillar atmospheres, the Monument (DR-18). |
| **Mobile** | **Every member page overflowed by 106px at 390px**; the member area had **no navigation at all** on phones. The public site had no mobile menu. | Portalled sheet + member tab bar; zero overflow on 29 page/audience pairs × 6 widths. |
| **UX** | Member header wrapped onto two lines at 1440px ("The house", "Miner ⛏", "E2E Admin"). Dashboard mission cards had no action and no route. | Account menu; every mission now has a door to where its work happens. |
| **Interaction** | "Mark complete" had no pending state; a quiz pass discarded its own review; on phones the course outline stood between the member and the lesson (spec §13). | All three fixed. |
| **Content** | Copy that was no longer true: "Wallet history arrives in Phase 7" beside a working wallet; "Spending opens in Phase 8"; "course player in Phase 5"; the public roadmap listed built phases as upcoming and promised member **transfers**, which the economy forbids; the THC page hard-coded reward amounts; the status page showed a hand-typed "Ledger tests: 16 ✓". | Every one corrected; the figures are live queries now. |
| **Accessibility** | `ink-3` at 3.4:1 (fails AA), input borders at 1.56:1, no skip link, auth pages without an `h1`, the Miner blocked pinch-zoom. | All fixed; axe (WCAG 2.1 AA) reports **zero** violations on every audited page at 1440 and 390. |
| **Performance** | Light already (102 kB shared JS). Risk was only in what 3D could add. | three.js lazy, idle-loaded, desktop-only, with a frame governor; homepage first-load 107 → 115 kB. |
| **Architecture** | Sound. One soft spot: `Button` lived in a client module that pages could not use for links, so eight pages re-implemented primary buttons by hand. | `buttonStyles()` in a plain module; hand-rolled buttons removed. |
| **Tests** | The e2e sign-in raced the redirect (DR-20). | Fixed the race, not the assertion: **39/39**. |

## Not changed, deliberately (and why)
- Rank names and count, the four programs, enrollment pricing, draft visibility on `/programs`: business
  decisions, listed as OQ-A…OQ-D in `TYCOONHOOD_DECISIONS.md`.
- The open DR-2…DR-9 security/ops items: outside a visual takeover, still tracked in the roadmap.

## After
Typecheck clean · lint clean · **101/101** tests · both production builds · e2e **39/39** · platform harness
**28/28** · zero horizontal overflow at 1440/1280/1024/768/390/360 · zero axe violations · no console errors.
